B2B 서비스를 개발·운영하며 업무의 맥락을 데이터 구조와 처리 방식에 연결하는 것을 중요하게 생각합니다. 현업 담당자와 지속적으로 소통하며 요구사항의 배경과 업무 흐름을 파악하고, 기능 구현과 데이터 정합성을 함께 고려해 왔습니다.

주어진 환경에서 더 효율적인 데이터 처리 방법을 찾고자 합니다. 온프레미스 레거시 환경에서도 데이터 접근 경로와 I/O를 살피며 쿼리와 처리 방식을 검토했습니다. 신규 테이블에는 선택도와 주요 조회·조인 패턴을 바탕으로 인덱스 설계를 제안하며, 설계 단계부터 효율적인 데이터 접근을 고민했습니다.

이러한 실무의 고민을 체계화하기 위해 데이터 모델링과 SQL 튜닝을 꾸준히 학습하고 SQLP를 취득했습니다. 앞으로도 개발 경험을 바탕으로 업무와 데이터를 함께 이해하고, 현재 시스템에서 개선할 지점을 지속적으로 찾아가는 개발자가 되고자 합니다.
