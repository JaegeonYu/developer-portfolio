업무를 이해하고, 데이터로 풀어갑니다.

B2B 서비스를 개발·운영하며 업무의 맥락을 데이터 구조와 처리 방식에 연결하는 것을 중요하게 생각합니다. 현업 담당자와 지속적으로 소통하며 요구사항의 배경과 업무 흐름을 파악하고, 기능 구현과 데이터 정합성을 함께 고려해 왔습니다.

데이터를 다룰 때는 결과뿐 아니라 DB 안에서 어떻게 동작하는지도 함께 봅니다. 대량 삭제에서는 변경 기록이 쌓이는 방식을 고려해 나눠 지우는 방법을 택했고, 중복 요청은 DB 행 잠금으로 처리 순서를 보장해 막았습니다.

이러한 실무의 고민을 체계화하기 위해 데이터 모델링과 SQL 튜닝을 꾸준히 학습하고 SQLP를 취득했습니다. 익힌 실행계획·인덱스 관점은 스터디원과 함께 쓰는 SQL 튜닝 채점 시스템을 만들며 직접 적용하고 있습니다. 앞으로도 개발 경험을 바탕으로 업무와 데이터를 함께 이해하고, 현재 시스템에서 개선할 지점을 지속적으로 찾아가는 개발자가 되고자 합니다.
