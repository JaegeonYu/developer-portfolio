# 개발자 포트폴리오 뼈대

`dist/index.html`을 브라우저로 열면 볼 수 있습니다. 빌드나 설치가 필요 없습니다.

- `dist/index.html`: 소개, 경력, 프로젝트, 기술, 연락처. 대괄호로 표시한 항목을 본인의 내용으로 교체하세요.
- `dist/style.css`: 색상, 타이포그래피, 반응형 레이아웃. 맨 위 CSS 변수로 주요 색상을 바꿀 수 있습니다.
- `dist/script.js`: 테마 전환, 현재 섹션 표시.

프로젝트 상세는 기본 HTML `details`로 펼칠 수 있습니다. 카드의 예시 그래픽은 실제 프로젝트 스크린샷으로 교체하세요. 실제 이력, 기술, 성과는 임의로 작성하지 않았습니다.

연락처를 채울 때 이메일은 `mailto:` 링크로, GitHub/블로그는 실제 주소를 가진 `a` 태그로 바꾸세요. 외부 글꼴을 불러오지 못할 때는 시스템 산세리프 글꼴로 표시됩니다.

구성 참고: https://min-hyuk.com/ 및 https://cdg-portfolio.com/ . 원본의 개인 정보나 프로젝트 내용은 사용하지 않았습니다.
